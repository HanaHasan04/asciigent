\begin{abstract}
% =========================================================
Visual abstraction is the process of discarding redundant low-level visual data---textures, photometrics, and uninformative pixel noise---and re-encoding semantic structures into a reduced, symbolic visual language. While recent advances in neural sketch synthesis like SketchAgent demonstrate that vision-language models (VLMs) can synthesize continuous vector strokes, we investigate whether this spatial capacity extends to a fundamentally more constrained and discrete medium: \textbf{ASCII art}. In ASCII art, a model must convey recognizable silhouettes using exactly 95 printable characters on a fixed $24 \times 48$ monospace grid. Characters here serve a dual role: simultaneously functioning as language tokens and spatial micro-primitives. This dichotomy introduces a core question: do autoregressive models draw through spatial reasoning or pure textual memorization, and does active visual perception enable meaningful self-correction? We introduce \textbf{ASCIIgent}, a training-free framework evaluating monolithic prompting baselines, agentic discrete tool-use loops, and multimodal visual feedback. Evaluating against structure-destroying scrambled controls to mitigate the text-reading bias of VLM judges, we reveal characteristic failure modes of monolithic generation (scanline drift, lexical leakage) and prove that intermediate visual feedback is essential for grounded spatial refinement, localized editing, and coherent keyframe animation.
\end{abstract}

% =========================================================
\section{Introduction and Related Work}
% =========================================================

\textbf{Visual Abstraction and Agentic Sketching.}
Visual abstraction is a core capability of biological and computational visual perception~\cite{hertzmann2020line}. Neural stroke models pioneered recurrent drawing representations~\cite{ha2017neural}, which later advanced toward semantic vector sketching~\cite{vinker2022clipasso}. Most recently, \textbf{SketchAgent}~\cite{vinker2025sketchagent} formalized sketch generation as a continuous perception--reasoning--action loop: a frozen multimodal LLM iteratively emits Bézier stroke control points, inspects the updated rasterized canvas, and refines the drawing. Concurrently, \textbf{VideoSketcher}~\cite{ren2025videosketcher} demonstrated that dynamic sketching can be decomposed into an LLM-guided high-level structural plan coupled with diffusion priors. We adapt and generalize this agentic paradigm to discrete character media.

\textbf{The ASCII Art Medium and its Challenges.}
ASCII art presents a uniquely rigid constraint: characters must occupy fixed coordinates in a monospace grid $\Sigma^{24 \times 48}$. Unlike continuous splines, characters possess discrete geometry: a forward slash \texttt{/} acts as a $45^{\circ}$ line segment, an at-sign \texttt{@} acts as a dense tonal patch, and a period \texttt{.} functions as point stippling. Monolithic autoregressive generation suffers from \textbf{scanline drift}: generating left-to-right, top-to-bottom forces the model to commit to features at row 2 that must align with geometry at row 22 hundreds of tokens later without intermediate visual verification or backtracking. Public archives like \texttt{asciiart.eu}~\cite{asciiart_archive} document decades of human designs, which language models have internalized during pretraining.

\textbf{The VLM Evaluation Confound.}
Evaluating ASCII art with multimodal models introduces a severe confounding factor: as shown by Wang et al.~\cite{wang2025textspeaks} and ASCIIBench~\cite{luo2025asciibench}, VLMs systematically suffer from text bias, recognizing concepts by reading characters rather than perceiving shapes. Our evaluation incorporates rigorous scrambled controls ($\textit{scramble-cells}$ and $\textit{scramble-ink}$) to isolate genuine visual recognizability.

\section{Methodology}
% =========================================================

\subsection{Canvas Representation and Format Contract}
The drawing canvas is defined as $C \in \Sigma^{H \times W}$ ($H=24$, $W=48$, $|\Sigma|=95$). Monospace rasterization $\mathcal{R}: \Sigma^{H \times W} \to \mathbb{R}^{H' \times W' \times 3}$ renders glyphs at exact pixel offsets without font kerning. The system enforces strict parsing: canvas overflows or non-ASCII escapes are flagged in a \texttt{ParseReport} and treated as structural defects.

\subsection{One-Shot Generation Baselines (P1)}
We evaluate three controlled one-shot prompting strategies across seen and held-out categories:
\begin{enumerate}
  \item \textbf{Zero-Shot:} Direct instruction: ``Draw a \{category\} on the $24 \times 48$ canvas.''
  \item \textbf{Few-Shot:} Same prompt preceded by four structurally diverse exemplar categories (\texttt{fish}, \texttt{house}, \texttt{tree}, \texttt{sailboat}) strictly disjoint from test categories.
  \item \textbf{Procedural (CoT):} The model explicitly plans the object's decomposition, bounding coordinates, and glyph selections in structured prose before emitting the grid.
\end{enumerate}

\subsection{Agentic Generation via Visual Feedback (P2)}
Instead of monolithic emission, ASCIIgent interacts with an \texttt{AsciiCanvas} through a discrete spatial action vocabulary:
\begin{itemize}
  \item \texttt{draw\_line}$(r_1, c_1, r_2, c_2, \textit{char})$: Bresenham line interpolation with automatic directional glyph selection.
  \item \texttt{draw\_rect}$(t, l, b, r, \textit{border}, \textit{fill})$: Axis-aligned bounding box.
  \item \texttt{shade\_density}$(t, l, b, r, \ell)$: Tonal fill from an ordered density ramp: \texttt{' '} $<$ \texttt{'.'} $<$ \texttt{':'} $<$ \texttt{'-'} $<$ \texttt{'='} $<$ \texttt{'+'} $<$ \texttt{'*'} $<$ \texttt{'\#'} $<$ \texttt{'\%'} $<$ \texttt{'@'}.
  \item \texttt{patch\_edit}$(r, c, \textit{lines})$: In-place localized subgrid overwrite.
  \item \texttt{erase\_rect}$(t, l, b, r)$: Region clearing.
  \item \texttt{finish}: Session termination.
\end{itemize}

\textbf{Feedback Ablation.} At the end of each turn, the canvas state is processed under three conditions: (1) \textbf{Visual (Ours):} rendered to a bitmap PNG and injected into the model's visual context; (2) \textbf{Text-Only:} presented as a raw character matrix; (3) \textbf{No-Feedback:} blind iteration without state representation.

\subsection{Evaluation Protocol (P3)}
To avoid subjective or text-contaminated assessments, our evaluation relies on three pillars:
\begin{enumerate}
  \item \textbf{Structural Metrics:} Ink ratio $\rho$ (density of non-blank glyphs), coverage (bounding box fraction), Shannon character entropy $H = -\sum p_i \log_2 p_i$, and automated flags: \texttt{spells\_name} and \texttt{degenerate}.
  \item \textbf{VLM Image-vs-Text Judge:} Dual independent queries to a frozen multimodal judge: unprompted open identification (``What does this picture depict?''), followed by a 1--5 semantic rating.
  \item \textbf{Scrambled Controls \& Control Gap:} For every drawing, we evaluate two controls: $\textit{scramble-cells}$ (uniform glyph shuffling destroying geometry) and $\textit{scramble-ink}$ (shuffling non-blank glyphs within the silhouette mask). The primary metric is the \textbf{Control Gap}:
  \begin{equation}
    \Delta = S_{\text{real}} - \max(S_{\text{cells}}, S_{\text{ink}})
  \end{equation}
  A positive gap $\Delta > 0$ validates genuine visual recognizability beyond lexical or density artifacts.
\end{enumerate}

\subsection{P2: Agentic Synthesis and Visual Grounding}
As shown in Figure~\ref{fig:agentic_turns}, the agentic system constructs subjects iteratively through our $\text{draft} \to \text{render} \to \text{perceive} \to \text{revise}$ loop. In Turn 1, the model drafts the outer head and torso silhouette. Inspecting the rendered bitmap in Turn 2, the agent identifies missing facial features and limbs, adding symmetric whiskers and seated front paws. In Turn 3, visual inspection guides the addition of a bell collar and curled tail. Without visual perception (Figure~\ref{fig:ablation}), multi-turn edits suffer from severe spatial drift and coordinate collisions.

\subsection{P3: CLIP Evaluation and Judge Calibration}
Evaluating with local CLIP ViT-B/32 against target text prompts confirms that agentic visual generation produces meaningful visual signals: \texttt{cat} achieved CLIP cosine similarity of 0.2947 vs. 0.2880 scrambled ($\Delta = +0.0067$); \texttt{bear} achieved 0.3044 vs. 0.2752 ($\Delta = +0.0293$). The dual text-vs-image judge experiment demonstrated that when evaluating purely on the rendered bitmap, the VLM judge assigned a score of 5/5 without text leakage.

\subsection{Extensions: Editing, Photography, Animation}

\textbf{P4: Conversational Editing.} Given a natural language request (``Add a pointy party hat with a star on top of the head''), the model issued a localized \texttt{patch\_edit} targeting rows 1--4 centered at column 18. Exactly 15 cells were modified directly above the head between the ears, leaving rows 5--23 completely untouched (Figure~\ref{fig:edit_and_anim}a).

\textbf{P5: Semantic Image-to-ASCII.} Conditioning directly on a photograph, the agent extracted structural contours into a sparse $24 \times 48$ representation ($\rho = 0.143$), filtering complex textures while retaining semantic identity.

\textbf{P6: Keyframe Animation.} Rather than regenerating the entire grid per frame (which causes body drift), our animation loop applies localized \texttt{patch\_edit} deltas onto the base keyframe. This guarantees 100\% frame-to-frame invariance of the head, torso, and limbs while smoothly animating blinking eyes (\texttt{o.o} $\to$ \texttt{-.-} $\to$ \texttt{\textasciicircum.\textasciicircum}) and a wagging tail (Figure~\ref{fig:edit_and_anim}b).

\section{Discussion and Comparisons}
% =========================================================

\textbf{Comparison to SketchAgent and VideoSketcher.}
SketchAgent~\cite{vinker2025sketchagent} operates in a continuous vector domain, outputting parametric Bézier coordinates stroke-by-stroke. In contrast, ASCIIgent operates over a \emph{discrete coordinate grid} using primitive commands (\texttt{draw\_rect}, \texttt{draw\_line}, \texttt{patch\_edit}). While SketchAgent performs single-stroke turns, ASCIIgent supports batched semantic operations followed by perceptual verification.

In VideoSketcher~\cite{ren2025videosketcher}, sketch animation is addressed by having an LLM decompose a drawing plan into a sequence of strokes, which a continuous video diffusion model (e.g. SVD/AnimateDiff) animates into pen-drawing footage. In discrete ASCII art, continuous stroke diffusion does not exist. However, the core conceptual insight of VideoSketcher applies directly to our framework in two distinct ways:
\begin{enumerate}
  \item \textbf{Drawing Process Playback:} Because ASCIIgent maintains a rigorous action history, the full drawing process can be rendered deterministically step-by-step (line by line, patch by patch), generating a discrete procedural drawing replay.
  \item \textbf{Subject Motion Animation:} For semantic object motion, our P6 keyframe generator employs autoregressive visual conditioning: each frame is synthesized by feeding the previous rendered bitmap into the model, enforcing strict boundary invariance while modifying dynamic sub-regions.
\end{enumerate}

\textbf{Limitations.} Free-tier API quotas constrain large-scale multi-model sweeps. Additionally, while the control gap $\Delta > 0$ protects against text bias, full calibration against crowdsourced human ratings represents the gold standard.

\textbf{Roadmap to CVPR.} Expanding this work for a formal CVPR submission requires: (1) multi-model sweeps across proprietary and open VLMs (GPT-4o, Claude 3.5 Sonnet, LLaVA-NeXT); (2) human perceptual preference benchmarks calibrating the control gap; and (3) hybrid neuro-symbolic search over discrete edit operations.

% =========================================================
\section{Conclusion}
% =========================================================
ASCIIgent establishes a rigorous framework for studying visual abstraction in discrete text spaces. We demonstrate that monolithic generation suffers from scanline drift and lexical contamination, while agentic discrete tool execution guided by active visual perception enables grounded refinement, localized editing, and coherent keyframe animation.
